# Sudoku Solver

A Python project exploring different algorithms for solving Sudoku puzzles.

## Current version — v1.0

The initial logical solver uses two techniques:

- Naked Single
- Hidden Single

The solver maintains candidate lists for empty cells and progressively eliminates impossible values.

## Planned features

- Performance optimizations
- Automated testing on Sudoku datasets
- Benchmarking and statistics
- Advanced logical solving techniques
- Recursive backtracking solver

## How to run

```bash
python3 Sudoku.py
```
